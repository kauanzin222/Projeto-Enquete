# 🎮 Poll Project - Desafio de Autonomia

![Status](https://img.shields.io/badge/Status-Finalizado-green)

Este repositório é muito significativo para o meu desenvolvimento, pois foi o primeiro projeto que realizei de forma totalmente independente, sem o auxílio do professor. Ele serviu como uma avaliação prática dos conhecimentos adquiridos no módulo, desafiando-me a construir uma interface web do zero utilizando apenas **HTML e CSS**.

## 🚀 Principais Aprendizados

A execução deste projeto permitiu validar competências essenciais para a minha evolução como **Desenvolvedor Full-Stack**:

- 👨‍💻 **Desenvolvimento Independente**: Primeiro teste de autonomia técnica, onde apliquei a lógica de resolução de problemas sem suporte instrucional direto.
- 🏗️ **Estruturação com HTML5**: Domínio da marcação semântica para criação de formulários de votação, organizando elementos de entrada e labels de forma clara.
- 🎨 **Estilização com CSS Puro**: Prática intensiva de estilização manual para reproduzir com precisão o layout proposto na imagem de referência, trabalhando com cores, fontes e alinhamentos.
- 📐 **Fidelidade Visual**: Foco em entregar um resultado final que respeitasse cada detalhe do modelo original, consolidando a base necessária para o uso de frameworks como o **Bootstrap**.

## 🛠️ Tecnologias Utilizadas

- **Estruturação**: HTML5.
- **Estilização**: CSS3 (Puro).
- **Evolução Técnica**: Este projeto serviu de base para a adoção posterior do **Bootstrap** como meu padrão de design.
